## 📊 Модели базы данных

### account.CustomUser
- email (уникальный, для входа)
- first_name, last_name
- position (Backend/Frontend/PM/Design)
- department (IT/Other)
- is_staff (админ)
- is_superuser (суперадмин)

### news.News
- title, short_description, full_text
- image
- published_date
- is_active, order

### news.Employee
- photo
- full_name, position, department
- contact (до 30 символов)
- is_active, order

### news.WelcomeBlock
- title, text
- is_active

### feedback.Feedback
- feedback_type (жалоба/предложение/отзыв)
- is_anonymous
- full_name, contact_type, contact_value
- message
- status (новое/в обработке/решено)
- admin_comment

## 🚀 Как запустить проект

### 1. Установка зависимостей
```bash
pip install -r requirements.txt
```

### 2. Настройка БД (.env)
```env
DB_NAME=postgres
DB_USER=postgres
DB_PASSWORD=postgres
DB_HOST=localhost
DB_PORT=5432
```

### 3. Миграции
```bash
python manage.py migrate
```

### 4. Создать суперпользователя
```bash
python manage.py createsuperuser
```

### 5. Запустить сервер
```bash
python manage.py runserver 8000
```

### 6. Открыть документацию
- Swagger: http://127.0.0.1:8000/api/v1/docs/
- Admin: http://127.0.0.1:8000/admin/
